# Contributing

Thanks for your interest. Issues are very welcome, whether it's a bug report, a number that comes out with the wrong digits or rounding, a build problem on some compiler or platform, or benchmark results from your own machines.

This repository is published as one commit per release, so I can't merge pull requests directly. When an issue leads to a fix, the fix goes into the next release, and I close the issue with a pointer to it.

A good bug report includes the input text or the value's bit pattern, the result you got, the result you expected, the compiler and its flags, and the target architecture. That's usually everything I need to reproduce it.

By contributing an idea or a test case, you agree that it may be used under the repository's licenses, CC0 1.0 Universal and the BSD Zero Clause License (0BSD).
